## About

This repository is a hands-on record of learning JavaScript from the ground up — core language fundamentals, DOM manipulation, and object-oriented and asynchronous programming — with every concept reinforced by real, runnable code and applied across **3 mini projects**: Tic-Tac-Toe (in two versions), Rock-Paper-Scissors, and a Currency Converter. No frameworks, no build tools — just clean, readable vanilla JavaScript, HTML, and CSS.

## Getting Started

No installation required — this is pure HTML/CSS/JS.

**1. Clone the repository**
```bash
git clone https://github.com/Tharunnagabramhagna/JavaScript-from-begineer-to-advanced.git
```

**2. Open any topic or project folder**
```bash
cd "JavaScript-from-begineer-to-advanced/4-Currency-Converter(mini project-3)"
```

**3. Run it** — either:
- open the `.html` file directly in your browser, **or**
- open the folder in VS Code and use the **Live Server** extension ("Go Live") for auto-reload.
